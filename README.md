# Dungeon text adventure: story files and web deployment

Open `ACTIVITY.md` for the student exercise. `main.py` is the updated version of the audio + web dungeon demo; `text/` holds descriptions that writing teammates can edit. The earlier notebook remains as a record of the preceding activity.

Use this `web_text_adventure` directory as the Git repository root. The workflow is at `.github/workflows/pages.yml` relative to that root. From here run `python -m pygbag .` to test locally.
